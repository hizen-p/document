# 仓库真实性检查

## 输入输出契约

- 前置条件：workflows/00_project_intake.md 确认输入中包含仓库链接或可定位的项目名称
- 产出物：仓库真实性检查结果表（存在性、官方性、Fork、源码完整性、README、构建说明、Release、维护状态）
- 消费者：workflows/04_pre_check.md 的 repository_validity_check 模块（引用结论，不重复执行）

---

## 模块

repository_validity_check

【重要度：5｜必须阅读】

---

## 检查

确认：

- 仓库是否存在
- 是否可访问
- 是否官方
- 是否 Fork
- 是否镜像
- 是否 Demo
- 是否实验项目
- 是否包含源码
- 是否有 README
- 是否有构建说明
- 是否有 Release
- 是否仍维护

## 最终判断

只允许：

- 推荐学习
- 可以学习但需注意
- 不建议作为主要学习对象

---

## 注意

维护状态无法确认时必须写：

当前资料不足，无法确认。

禁止根据项目最后提交时间以外的信息猜测活跃状态。

# Server Domain Profile

适用：

- Web 后端服务
- API 服务
- 微服务
- RPC 服务
- 网关
- 应用服务器

---

## request_lifecycle

【重要度：5｜必须阅读】

分析请求完整生命周期：

Request
↓
Router
↓
Middleware
↓
Business
↓
Response

只保留项目真实存在的阶段。

如果存在异步处理、消息队列、回调，补充分析。

---

## middleware_analysis

【重要度：4｜强烈建议】

分析中间件链：

- 中间件注册方式
- 执行顺序
- 典型中间件（鉴权 / 日志 / 限流 / CORS）
- 中间件间数据传递

仅存在中间件机制时分析。

---

## database_flow

【重要度：4｜强烈建议】

分析数据库交互流程：

业务请求
↓
数据访问层
↓
ORM/SQL
↓
数据库
↓
结果返回

分析点：

- 连接池
- 事务管理
- 查询构造
- 结果映射

仅存在数据库交互时分析。

---

## cache_analysis

【重要度：3｜按需查阅】

分析缓存机制：

- 缓存层级（本地 / 分布式）
- 缓存策略（LRU / LFU / TTL）
- 缓存一致性
- 击穿/雪崩防护

仅存在缓存机制时分析。

---

## auth_flow

【重要度：4｜强烈建议】

分析认证授权流程：

请求
↓
身份认证
↓
权限校验
↓
业务执行

分析点：

- 认证方式（Token / Session / OAuth / JWT）
- 权限模型
- 鉴权失败处理

仅存在认证授权时分析。

---

## deployment_architecture

【重要度：4｜强烈建议】

分析部署架构：

- 进程模型
- 容器化支持
- 集群部署
- 服务发现
- 配置中心

仅存在明确部署架构时分析。

# Developer Tool Domain Profile

适用：

- CLI 工具
- 构建工具
- 包管理器
- 编译器/解释器
- 静态分析工具
- Linter/Formatter
- 调试器
- 版本控制工具
- 脚手架/模板工具

---

## cli_entry_analysis

【重要度：5｜必须阅读】

分析命令行入口：

命令参数
↓
参数解析
↓
子命令分发
↓
核心执行
↓
结果输出

只保留真实存在的阶段。

---

## core_pipeline

【重要度：5｜必须阅读】

分析工具的核心处理流水线。例如：

构建工具：
源码
↓
解析
↓
转换
↓
打包
↓
产物

静态分析工具：
源码
↓
AST 构建
↓
规则匹配
↓
问题报告

必须根据项目实际类型确定流水线，不得套用固定模板。

---

## plugin_extension

【重要度：4｜强烈建议】

分析：

- 插件加载机制
- 插件 API
- 插件生命周期
- 配置扩展

仅存在插件系统时分析。

---

## config_system

【重要度：4｜强烈建议】

分析：

- 配置格式
- 配置加载顺序
- 默认值
- 覆盖策略
- 校验机制

---

## output_format

【重要度：3｜按需查阅】

分析：

- 输出格式
- 报告生成
- 退出码定义

---

## performance_strategy

【重要度：3｜按需查阅】

分析：

- 增量处理
- 缓存策略
- 并行处理
- 内存优化

仅存在明确性能优化时分析。

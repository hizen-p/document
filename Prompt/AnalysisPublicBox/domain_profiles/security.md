# Security Domain Profile

适用：

- 加密库
- 认证授权框架
- 安全扫描工具
- 入侵检测
- 防火墙/网关
- 密钥管理
- PKI 系统
- 安全审计工具

---

## crypto_primitive_analysis

【重要度：5｜必须阅读】

分析项目使用或实现的密码学原语：

- 对称加密（AES / ChaCha20 / SM4）
- 非对称加密（RSA / ECC / SM2）
- 哈希（SHA-2 / SHA-3 / SM3）
- 消息认证码（HMAC / CMAC）
- 数字签名
- 密钥交换（DH / ECDH）

必须依据实际源码确认，不得根据项目名称假设。

## auth_flow_analysis

【重要度：5｜必须阅读】

分析认证流程：

凭证输入
↓
身份验证
↓
令牌签发
↓
令牌校验
↓
权限判定
↓
资源访问

只保留真实存在的阶段。

## authorization_model

【重要度：5｜必须阅读】

分析授权模型：

- RBAC（基于角色）
- ABAC（基于属性）
- MAC（强制访问控制）
- ACL（访问控制列表）
- OAuth 2.0
- OIDC
- SAML

仅存在授权机制时分析。
